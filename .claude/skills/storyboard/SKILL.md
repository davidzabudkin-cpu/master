# Storyboard

Erst denken, dann rendern. Die dokumentierten Wiederholungsfehler (Bild passt nicht zum gesagten Wort, Animation läuft nicht zu Ende, Szenen zu kurz/zu lang, gleiche Szene mehrfach, zu viel Text statt Szene) entstehen, wenn direkt gebaut wird. Das Storyboard fängt sie auf Papier ab, wo eine Änderung nichts kostet.

Vorher lesen: `content-handwerk/references/wissen.md` §1 (Hook) und §5b (Prinzipien), dazu den Projekt-Skill mit seinen Stilregeln (sprech-reel, produktfilm). Das Storyboard legt **was und wann** fest; **wie es aussieht** bestimmt der Projekt-Skill.

## Ablauf

1. **Ein Satz**: Was soll der Zuschauer am Ende wissen/fühlen/tun? Für wen genau?
2. **Ende zuerst**: letzte Zeile + letztes Bild. Beim Short: führt sie zurück zur ersten (Loop) oder gibt sie einen Grund fürs lange Video?
3. **Hook bauen**: Key Visual → Hook-Format → gesprochene Zeile → 3–5 Wörter Text. Drei Varianten, eine wählen.
4. **Beats** dazwischen, verbunden mit „aber“/„deshalb“.
5. **Tabelle** füllen (unten).
6. **Gates** prüfen, Schwachstellen umschreiben.
7. **David zeigen** (Kurzfassung: Hook-Varianten + Beat-Liste in 6–10 Zeilen), dann bauen. Bei Serien nur das erste abnehmen lassen.

## Tabelle

| # | Zeit | Zweck | Gesprochen (wörtlich) | Key Visual | Text im Bild | Motion / Kamera | Figur | Ton |
|---|---|---|---|---|---|---|---|---|

- **Zweck** ist eines von: Hook-Kontext · Stopp · Snapback · Beleg · Wendung · Rehook · Auflösung · Loop/CTA.
- **Key Visual**: das eine Ding, das der Zuschauer sehen soll. Es zeigt genau das Wort, das gerade fällt.
- **Text**: max. 3–5 Wörter, konkret (Zahl, Name), oben oder Mitte, nie doppelt zu den Untertiteln.
- **Motion / Kamera**: Start- und Endzustand nennen („Balken wächst von 0 auf 40, steht 0,5 s“), damit jede Animation zu Ende läuft. Eine Bewegungsidee pro Beat.
- **Figur**: Pose/Blick/Aktion, nur wenn sie etwas zur Aussage beiträgt.
- **Ton**: Stimme immer; Musik/SFX nur mit Grund. Stilvorgaben des Projekts gelten (REMIRA: siehe remira-erklaervideo; sonst weiche, musikalische Sounds).

## Gates

**Hook (0–3 s)**
- Thema klar durch Bild + Ton + Text gleichzeitig, in der ersten Satzhälfte.
- Ohne Ton verständlich, worum es geht.
- Kein Logo, kein Intro, kein „Hallo“.

**Verlauf**
- Alle 2–3 s ändert sich sichtbar etwas, das zur Aussage gehört.
- Kein Beat wiederholt ein Bild eines früheren Beats.
- Jeder Beat hat genug Zeit: gesprochene Dauer + 0,3–0,5 s Stand für das Endbild.
- Bei 60–70 % eine neue offene Frage.
- Jede Zeile macht die nächste nötig. Zeile streichen, ohne dass etwas fehlt? Dann streichen.

**Ende**
- Auflösung hält, was der Hook versprach.
- Letzte Zeile ist allein teilbar oder schließt den Loop.
- Höchstens ein CTA, gesprochen, konkret.

**Machbarkeit**
- Jedes Key Visual ist mit den vorhandenen Bausteinen baubar oder als neues Asset benannt (mit Kosten).
- Zahlen im Bild stimmen mit Skript und Quelle überein.
