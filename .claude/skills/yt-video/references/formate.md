# Video-Formate (Aufbau je Format)

Wähle das Format nach Thema und Referenzen. Alle Formate nutzen Hook-, Spannungs- und Storytelling-Regeln aus `skript.md`/`storytelling.md`.

## A. Explainer („[X] erklärt wie für 5-Jährige“)
Hook (Person + Paradox + Betrag) → Analogie-Welt (Dorf, Laden, Küche) → Mechanismus in 3 Schritten (je Analogie-Szene → echtes Beispiel → Alltagsvergleich → Brückenfrage) → Gegenseite → Wen betrifft es → 3 Warnzeichen/Takeaways → Rückgriff auf Hook. 10–14 min.

## B. Firmen-/Personen-Story („How X actually built Y“)
Erprobt an einem Firmenporträt (4 Feedback-Runden, Vorlage für jede Story):
- **Mehrere Menschen mit rotem Faden:** Hauptfigur über Jahrzehnte, ausgelachter Pionier, der später zurückkommt, Ideengeber, grummeliger Boss, eine Zuschauer-Stimme mit Witzen.
- **8–10 Kapitel mit Titelkarte (Ort + Jahr)**, jedes endet mit einer Frage; keine Jahre überspringen, ohne zu erklären, warum die Firma groß wurde.
- Siege groß feiern (Stempel + Konfetti). Technik früh kurz als Grundlage, einmal komplett in einem eigenen Kapitel. Ende greift den Anfang auf.
- Dialoge sind nachgestellt, echte Zitate nur mit Beleg.
- Bild: Totale → Nah pro Szene, Kapitelkarte steht 1,6 s allein mit getipptem Titel, leises Tippgeräusch.

## C. What-If („Was wäre, wenn du jeden Tag 1 Cent verdoppelst?“)
- Titel im What-If-Format, Thema (Cent/Geld) sofort im Bild/Thumbnail sichtbar.
- **Interaktion „Wähle deinen Tag“:** Optionen nur zeigen, nicht vorlesen; Pause zum Merken („Wähl eine. Merk sie dir. Okay?“). Eine Interaktion = ein Animationsablauf.
- Regeln/Leiter klar zeigen, Käufe als Simulation (Was kann man sich an Tag X leisten?), Zähler läuft durch.
- Wiederkehrende Requisiten bleiben am selben Ort.
- Wiederkehrende Einblender (z. B. „Fakten-Check“) max. 2× pro Video.
- Story-Variante (Strichfiguren, „What if you…“, 12 Beats): Skill `story-film`.

## D. Listicle / Top-N
Nur mit starkem Rahmen: eine Leitfrage, die erst bei Platz 1 beantwortet wird; jede Position = Mini-Story (Ort, Person, Wendung); Zähler/Rangleiste als wiederkehrende Grafik; Platz 1 wird im Hook angeteasert.

## E. Mythos-Check
Verbreiteter Irrtum → warum ihn alle glauben (fair) → Beleg dagegen (Quelle!) → was stattdessen stimmt → was das für dich heißt. Grafik `mythfact`/Durchstreichen. Heikle Behauptungen ehrlich auflösen: Aussage der Firma + was belegt ist + Gegenbeispiele + offene Bewertung.

## F. Kurzfilm / stumme Story
Skill `story-film`.
