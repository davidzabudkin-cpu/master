# Qualitäts-Checkliste – VOR jeder Vorschau abhaken

Diese Punkte stammen aus ~15 Videos und je 3–6 Feedback-Runden. Jeder davon hat einmal eine ganze Korrekturrunde gekostet. **Erst alles abhaken, dann schicken.**
★ = wurde mehrfach angemerkt. **Neue Feedback-Punkte des Nutzers sofort unten unter „Eigene Regeln“ eintragen** – so lernt der Skill seinen Geschmack.

## A. Skript und Aufbau
- [ ] ★ Hook = echte Person/Ereignis + Paradox + konkreter Betrag; Neugier-Satz danach
- [ ] ★ Keine Vorstellung („Hi, ich bin …“), kein Kapitel-Fahrplan, nie „Kapitel 1“ / „Erstens“
- [ ] ★ Roter Faden: eine Leitfrage, sichtbar über eine wiederkehrende Grafik; Ende greift Anfang auf
- [ ] ★ Einfache Alltagswörter; Fachwort nur mit Sofort-Erklärung
- [ ] ★ Große Zahlen selten, nie drei hintereinander, jede einmal greifbar gemacht; keine Zahlenketten
- [ ] ★ Mechanismus mit nachrechenbarem Beispiel (wer zahlt wem was)
- [ ] ★ Jede schwierige Stelle ganz erklärt: was, wie, warum, Folge
- [ ] ★ Alltagsvergleich sitzt sofort und ist nachgerechnet
- [ ] ★ Antworten erst am Ende; jedes Kapitel endet mit einer neuen Frage
- [ ] ★ Auswahl-Fragen nicht vorlesen (Optionen zeigen, Pause)
- [ ] Zitate im Original, echte Namen, Gegenseite fair, ehrliche Wortwahl bei Zahlen
- [ ] Witze ohne Vorwissen verständlich
- [ ] Heikle Behauptungen ehrlich aufgelöst (Aussage + Beleg + Gegenbeispiel)
- [ ] Kein „Teil 2“ versprochen, kein Rätsel-Ende

## B. Bild, Szene, Animation
- [ ] ★ **Bild = genau das Gesagte** (Namen zeigen, Aufzählungen bebildern, Zahlen als Bild + Zahl)
- [ ] ★ Bewegung geplant, bevor Bilder entstanden
- [ ] ★ Hook: viel Bewegung, nacheinander statt übereinander; kein leerer Bildschirm
- [ ] ★ Echte Personen als erkennbare Karikatur, in allen Szenen gleich
- [ ] ★ **Animation läuft bis zum Schnitt** – nichts friert ein, nichts wird abgeschnitten
- [ ] ★ Nichts taucht aus dem Nichts auf, nichts springt
- [ ] ★ Figuren und Orte konsistent (gleicher Laden, gleiche Figur, Requisiten am selben Platz)
- [ ] ★ Kaum Zoom, kein Wackeln, keine starken Ausschnitt-Vergrößerungen
- [ ] ★ Text/Schilder nie über Köpfen, Gesichtern, Hauptmotiv oder Werten
- [ ] ★ Kein Bild kürzer als ~1,5 s, Grafiken ≥ 3 s lesbar
- [ ] ★ Jahreszahlen, Orte, Namen als Schild, wenn gesprochen
- [ ] ★ Jedes Bild möglichst nur einmal
- [ ] ★ Kein Aufblitzen von Elementen an Satzgrenzen
- [ ] Pfeile mit sauberer Spitze, Haken rund
- [ ] Keine physikalisch unsinnigen Szenen, keine schwebenden Gegenstände
- [ ] Wenig Text im Bild; Pop-Karten sparsam; wiederkehrende Einblender max. 2× pro Video
- [ ] Abwechslung: nicht dieselben Szenenbilder immer wieder
- [ ] Hell/dunkel: auf dunklem Grund keine dünne weiße Schrift; Überschriften nie über Grafiken

## C. Ton
- [ ] ★ Effekte weich, echt, nur bei sichtbarer Handlung; kein Pop, kein Rauschen
- [ ] Alle Stimmen gleich laut und ähnlich hoch
- [ ] Keine abgeschnittenen Silben an Satzkanten (an Stille geschnitten)
- [ ] Max. 1 s Stille am Ende, nirgends Pausen > 1,2 s
- [ ] Tempo-Fassung: Bildlänge = Tonlänge (`tempo.py` sagt OK)

## D. Technik/Ablauf
- [ ] Feedback mit Zeitstempel → Szene gefunden → **alle gleichartigen Stellen mitgeprüft**
- [ ] Nach jeder Fassung: Standbilder aller geänderten Szenen + Endbild jeder Animation angesehen
- [ ] Kosten genannt, Ledger aktuell
