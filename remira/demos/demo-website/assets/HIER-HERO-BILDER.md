# Hero-Figuren einsetzen

1. Bilder hier ablegen: `hero-frau.webp` (Remira-Heldin, Hero links) und `hero-mann.webp` (Remira-Held, Hero rechts + Kontakt-Abschnitt).
2. In `main.js` die Zeile `const HEROES = { frau: '', mann: '' };` ändern zu `{ frau: 'hero-frau.webp', mann: 'hero-mann.webp' }`.

Format: Hochkant 3:4, ca. 900×1200 px, < 250 KB. Freigestellt oder mit ruhigem, dunklem Hintergrund.
