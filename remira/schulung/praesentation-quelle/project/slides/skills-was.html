Skills

Ein Skill ist eine Einarbeitungsmappe

Anleitung, Schritt für Schritt

Regeln: was immer, was nie

Gute Beispiele

Einmal aufschreiben – jedes Mal richtig.

Wie eine Mappe für neue Kolleginnen: Claude liest sie von selbst, sobald die Aufgabe passt.

Das Beste: Claude schreibt den Skill selbst, wenn ihr erzählt, wie ihr arbeitet.

Skills (1 Min.). Zurück zum Praktikanten: Damit man nicht jedes Mal von vorne erklären muss, bekommt er eine Mappe. Das ist ein Skill. Beispiel aus meinem Alltag: Mein Website-Skill weiß, wie meine Seiten aussehen sollen, welche Fehler ich nicht mehr will und wie das Hochladen geht. Ich sage nur „Mach eine Seite für Café X“ – den Rest kennt Claude aus der Mappe. Skills gibt es in Claude unter Einstellungen → Fähigkeiten/Skills (in der App nachschauen).
